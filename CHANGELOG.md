# Changelog

## 1.0.0 — 2026-09-13

Initial release of Thought Trace.

### Added

- Reconstruct how ideas and decisions evolved across native Codex and Claude Code sessions.
- Scope requests by time, project, topic, evolution, decisions, or open questions, using `/trace` or natural language.
- Explain changes, alternatives, outcomes, and unresolved questions with source references and explicit evidence limits.
- Read accessible session history directly without requiring exports, a database, an index, or a background service.
- English and Simplified Chinese READMEs with matching landscape usage infographics.
- Version `1.0.0` and repository metadata in the skill, following the RPD skill format.
